# 全文 fixture（LaTeX ソース）

`$meta` を持てないプレーンな `.tex` なので、来歴はここに書きます。

**これらは合成です。** 実在の論文ではありません。この開発環境は外向き接続を遮断していて
（DECISIONS.md D-024）、arXiv からソースを取得できないため、**公開されている LaTeX の
構造だけを手で起こし、中身は書き下ろしました**。数学は標準的で正しいものを選んでいます
（ガウス積分、調和振動子）— 「抽出できた」と言うためには、抽出結果が実際に検算できる
必要があるからです。

各ファイルの `manifest.json` に、その本文に付くライセンスを書いています。**論文メタデータの
ライセンスではなく本文のライセンス**です（仕様書 21 節。arXiv はメタデータが CC0 でも
本文は著者の選んだライセンス）。`permissive.tex` は CC-BY-4.0、`arxiv-licence.tex` は
arXiv 非独占ライセンスで、**後者は意図的に拒否される**ケースです。

すべて CC0-1.0 でこのリポジトリに置いています。
